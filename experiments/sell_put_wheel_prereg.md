## 2. 规则

### 2.1 账户与额度
- 纸面本金 $100,000，独立账本（`PATHS.sell_put_state`），**不并入**卖权选择器预注册、跨式预注册，也不碰它们的账本。
- 每只一次 1 张。单只 put 现金担保（行权价 × 100）≤ NAV 的 20%；put 担保 + 持股市值 ≤ NAV 的 60%（开新 put 之前判）。
- 同一只已有未到期 put、持股、或未到期 call 时，不再叠加新的 put。

### 2.2 卖 put
- **行权价** = 不高于「接货价」的、满足 §2.4 的最高一档；接货价缺省时为占位：开仓当天现价 × (1 − 10%)，记录里标 `accept_price_source = "placeholder"`。
- **到期日**：期限窗口 55~90 天内离 70 天最近的到期日（同距取更晚）。
- **成交价** = bid（保守）。收到的权利金立即记入现金；担保现金不扣、只占额度。
- 每个交易日扫描后评估（财报前后照卖，不避开）。没开成的原因逐只记在 `meta.last_run.skipped`（原因码表 `SKIP_REASONS`）。

### 2.3 到期结算
- 到期日**当天及之前**不结（结算要那一场的定稿收盘，当晚恒取不到）；之后第一次运行起按**到期那一场**的官方收盘结算（`options_paper_leg._default_close`，自报场次，场次不符 ⇒ 延期，**绝不拿前一天的价顶替**）。
- put：收盘 < 行权价 ⇒ 被行权接货（现金 −行权价 × 100，持股 100，成本 = 行权价 − 已收权利金）；否则作废，权利金留下。
- call：收盘 > 行权价 ⇒ 被叫走（现金 + 行权价 × 100，一圈结束）；否则作废，持股不动，下一个交易日再卖。
- 美式提前行权不建模（实务里 put 提前被行权多见于深度价内 + 临近除息，call 提前被叫走多见于除息前）；这是已知偏乐观的地方。

### 2.4 「能卖」的合约
bid > 0、ask ≥ bid、(ask − bid) / mid ≤ 15%、未平仓量 ≥ 100。点差上限与跨式账本的口径一致（15%）；任何一条不满足就是对应原因码，不拿次好的顶替。put 从最高的合格档往下找（行权价更低 = 更符合「愿意买入」，只是权利金更少）。

### 2.5 多只同时能开
按「年化权利金」（bid ÷ 行权价 × 365 ÷ 天数）从高到低依次判额度。**这条是我对「选溢价标的」的字面解读，待用户确认。**

### 2.6 被行权后的 covered call
- 每股成本底线 = 接货价 − 该次 put 权利金（**之后 call 的权利金不再降这条线**，免得越卖越低把亏损锁死）。
- call 行权价 ≥ 成本底线；到期窗口 25~50 天、离 35 天最近；在合格的 call 里取 |delta| 最接近 0.25 的一档；成交价 = bid。
- 没有合格的 call（行权价都低于底线 / 点差宽 / 缺 delta）⇒ 当天不卖，原因记下，次日再试。
- 被叫走 ⇒ 这一圈结束；之后该标的回到 §2.2。**没有止损、没有止盈**：被行权是目的，不是亏损。

## 3. 记什么
- `lots.jsonl` 当前持仓（每只一条）· `events.jsonl` 卖出 / 作废 / 接货 / 卖 call / 作废 / 被叫走 · `equity_curve.jsonl` 每日净值与各标的收盘 · `meta.json` 现金与最近一次运行的跳过 / 延期 / 取不到链的原因。
- 盯市：未到期的腿按 mid（取不到合格双边报价就沿用上次 mark 并累计 `stale_days`），持股按当天 CBOE 链的标的价（盘后快照 = 收盘）。净值 = 现金 + 持股市值 − 未到期腿负债。

## 4. 对照基准（页面并排，**不是检验的零假设**）
1. **同价位限价买入**：每笔 put 开仓当天，在同一行权价挂 GTC 限价买入 100 股，到该 put 到期日之前收盘 ≤ 行权价即视为成交（只有收盘价，所以是保守的成交判据）。
2. **一直持有**：put 开仓当天收盘价买入 100 股，持有到该 put 到期日。
两条都不含权利金、不含 call。它们回答「卖 put 比直接买更好 / 更差多少」，不回答「该不该买这只」。

## 5. 失败必须看得见
整轮抛 / 全部标的取不到期权链 / 到期腿结算延期 ≥ 3 个日历日 ⇒ `scan_timing.counters()["sell_put"]` → `alert_manager._check_sell_put` ⇒ **P2**（个别标的当天取不到链、结算延期 1~2 天是常态，不报）。账本写失败走 `ledger_io` 的源头登记（⇒ P2）。
