## 1. 问题

网站上那套策略（§3 冻结的回测配置），在**当前世代**里，每笔交易的期望收益是否 > 0？

只有答「是」，才有理由按 §6 放大仓位。答「否」时维持最小仓位 —— 优势≈0 时，
凯利最优仓位就是≈0，加仓只放大回撤。

## 2. 假设

- H0：当前世代每周入场交易的平均收益（方向调整后 gross，%）的期望 = 0。
- H1（单侧）：期望 > 0。
- 统计量：N 个周均值的单样本 t，df = N−1，**t 分布**（不是正态近似），单侧 p。
- 判定：`p < alpha` **且** 样本均值 > 0 ⇒ 检出优势；否则未检出。

## 4. 单位、样本与就绪

- **单位 = 入场日所在 ISO 周**。每周取该周入场交易 `gross_pct` 的均值作为一个观测；
  无入场交易的周不算单位。理由：同一周的交易共享同一段大盘，彼此不独立（旧数据里
  5/19、8/17、9/14 各有 3–4 笔同日止损）。
- **世代**：只收 `entry >= ic_rerun_readiness.cohort_start()["date"]` 的交易。世代表每追加一条，
  计数从零开始 —— 旧代码的收益回答不了新代码的问题。
- **排除**：`WINDOW_CUTOFF`（回测窗口结束时未到期、按 0 收益强平，不是真实结局）。
- **结清**：一周的周日之后满 `settle_grace_days` 天才入样本，保证就绪后样本不再变。
- **就绪** = 已结清单位数 ≥ `n_weeks`。
- **样本 = 当前世代的前 `n_weeks` 个单位，一个都不多**。就绪后无论何时再跑，读到的都是同一批周，
  答案不变 —— 这就是「只跑一次」，不存在「多攒几周再看」（optional stopping）。
- **未就绪时盲化**：执行器只返回周数 / 笔数，不计算、不返回均值 / t / p / 判定。

## 5. 功效（如实）

旧世代周均收益 SD ≈ 4.17%。单侧 α=0.05、功效 80%：

| 真实周均优势 | 所需周数 |
|---|---|
| +1.5% | 48 |
| +1.0% | 108 |
| +0.75% | 191 |
| +0.5% | 430 |

N=52 ⇒ 最小可检出效应（MDE）≈ **+1.44%/周均**。更小的真实优势大概率读成「未检出」——
**「未检出」不等于「证明没有优势」**，只等于「证据不足以支持加仓」。

⚠️ **时间代价**：52 个有交易的周 ≈ 一年多，且前提是这一年里评分逻辑不再登记新世代。
登记当天一天就登记了 4 条世代边界 —— 若继续这个节奏，本检验**永远不会就绪**。
想要答案，就得在某个时点冻结评分代码。这是用户的取舍，本文件不替用户做。

## 6. 判定后的行动（登记时写死）

- **检出优势**：允许按半凯利估计仓位上限：`f = 0.5 × 均值 / 方差`（用本检验样本的周均值与方差），
  且不超过现有方向仓位上限的 2 倍；放大后重新登记一次新检验（新配置 = 新策略）。
- **未检出**：维持现有仓位或更小；不因「均值为正但不显著」而加仓。
