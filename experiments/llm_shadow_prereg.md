# LLM 影子 A/B 预注册（v0.45.555，2026-10-19，**看数据之前**写的）

**问题**：同一天、同一份输入下，开着 LLM（Opus 5.5 低 effort + 精简 Oracle 提示词）算出来的方向，T+7 命中率是否与纯规则不同？

**为什么前瞻**：历史重跑不可行——输入不是当时的快照；模型知识截止 2026-06，对 3~6 月行情有前视偏差。
历史上网站总收益对早期样本极敏感（含全部样本 −0.99%，剔除 ≤04-17 的 280 行 −10.83%），但早期段混着行情、
CRCL 02-26 一笔 +28%、04-26 ScoutBee 重平衡，**不能**据此说 LLM 有效。

## 两条臂
- **LLM 臂**：`llm_shadow_scan.py --run` 的 `final_score` / `direction`（Opus 5.5 低 effort + 精简 Oracle 提示词，蜂层面与 Queen 层面的 LLM 都开）。
- **规则臂**：**生产当天自己的规则引擎结果**——生产库 `predictions` 里同日同标的的 `final_score` / `direction`（生产永远 `--no-llm`）。
  生产收盘后 14:00 才跑，影子扫描紧随其后：价格静止，影子根的 `cache/` 也已被生产更新过，两边输入一致。
- ⚠️ 影子 `swarm_results` 里的 `rule_score` **不是**规则臂。它由各蜂的维度分算出，而蜂在 LLM 模式下已把 LLM 混进自己的分数
  （OracleBee 以 0.6 权重混入 `smart_money_score` 并可改写方向）；Queen 的 LLM 只是再加一层。
  它只用于描述性分解（Queen 层 = `final − rule_score`；蜂层 ≈ `rule_score − 生产 final`，含两次扫描的输入噪声），不参与检验。

## 入选
- 只用 `quality.healthy == true` 的 LLM 日（有预算 / 定价拒绝、LLM 一次没调成、截断率或 JSON 失败率 > 10%、
  蒸馏走 LLM 的标的 < 80% 的日子**整天剔除**——那一天的「LLM 臂」大部分是规则臂）。
- 标的日要 LLM 臂的最终分与方向、规则臂（生产）的最终分与方向都齐全；T+7 结果取生产库同日同标的的 `price_at_predict` 与 `close_t7`，
  缺价 / 未到期 / 生产里没有该日该标的，都不入检验（缺了多少如实报出）。

## 主检验（唯一）
- 只看**两臂方向不同**的标的日（方向相同的对差异无贡献）。判对错用仓库既有的 `outcome_utils.determine_outcome_triplet`；
  任一臂「模糊」的剔除，不当作两边都错。
- 统计量：「只有 LLM 对」b 与「只有规则对」c；**McNemar 精确检验，双侧**，α = 0.05。
- **不做**多重比较之外的任何子集挖掘（按标的 / 按月 / 按分数段拆分都不是本协议的检验，只能作探索、不能下结论）。

## 样本量门槛（没到之前报告工具**不计算**命中率）
- 健康的 LLM 日 ≥ **20**；
- 「方向不一致且 T+7 已出」的标的日 ≥ **60**。

两条同时满足才计算并报告。门槛先于数据定下，不随结果调整。
功效说明：b 与 c 在 H0 下各 1/2，n = 60 时只能检出较大的差（例如 b:c ≈ 40:20 时 p ≈ 0.01）；
小的真实差异需要更多天——**样本不够时的正确结论是「还没有证据」，不是「没有差别」**。

## 停止与改动
- 提示词 / 模型 / `max_tokens` / 精简规则任何一项改动 ⇒ 新的一代，**重新计数**，旧样本不与新样本合并。
- 当前这一代的定义（`llm_shadow_scan.py` + `llm_service.py`，v0.45.555）：模型 `claude-opus-5-5`、`effort=low`、
  `max_tokens = max(请求×3, 请求+1024)`、Oracle 提示词按 `_compact_options_for_llm` 精简（溢价前 8 ∪ 成交量前 5 ∪ vol/OI 前 5）。
- 每日硬上限 $3，按日期轮换覆盖约 22/30 只；覆盖名单逐日记在状态文件里，检验只用实际覆盖到的标的日。

## 已知局限（先写下，免得事后当成发现）
1. 两条臂**共享**取数、ML、政体权重等非 LLM 部分；比较的是「LLM 开 / 关」，而不是别的差异。两次扫描之间的输入噪声（新闻、
   取数时点）会被算进差异里——影子 `--control`（LLM 关）与生产的逐只分差就是这份噪声的度量，**第一次真跑之前先跑一次**，
   并在 `llm_shadow_report` 的描述里和 LLM 臂的分差对照。
2. 同一提示词重复跑，LLM 输出有随机性（最小样本里分数 / 方向一致、`signal_type` 文案三次互异）。
3. 精简后的两条大 Oracle 提示词从未与原版对照过。
4. 每日硬上限 $3 只够约 22/30 只，覆盖名单按日轮换；检验只用实际覆盖到的标的日。
