## 1. 动机与证据等级

用户（2026-10-21）：想让系统「根据每个标的的情况与财报前的溢价数据，判断卖宽跨好还是卖同价跨式」。可检验的最小命题：

> 在账本自己的成交与定仓约定下，**同一事件、同一入场日、同一到期日**，卖 25Δ 宽跨的盈亏与卖 ATM 跨式的盈亏有系统差异。

| 依据 | 等级 | 说明 |
|---|---|---|
| 宽跨盈亏平衡带更宽、权利金更少 | 结构事实 | 不是证据，是几何 |
| 「宽跨对尾部更稳」 | 无 | 账本按权利金定仓：权利金少 ⇒ 张数多（T 09-29：跨式 38 张 / 宽跨 150 张，名义股数 3,800 vs 15,000），尾部风险被定仓规则放大回来 |
| 25Δ 腿的可成交性 | 弱 | 同一份收盘后快照里 25Δ 腿点差常 > 15%（T put 93.75%）；`earnings_vol_signal` 文件头记过 COST 25Δ 盘后 27.6% vs 盘中 9.6% |
| 单只票的历史尾部频率 | 弱 | 每票 ≤ 8 次财报，「带外 k/8」的 95% 区间约 7%–59%（T，k = 2） |

所以**不预设方向**，检验是双侧的；「选择规则」不在本协议内（§9）。

## 2. 影子记录什么（只记录，不进任何判断）

对每个**被账本真正开仓**的跨式（多 / 空都记），同一天、同一份快照 `quote_set.contracts` 里的 `c25` + `p25`
（delta 最接近 ±0.25 的 call / put，**与跨式同一到期日**），入场时落盘：

- 两腿的 OCC 符号、行权价、bid / ask / delta / OI / 点差、`quote_ok`；
- 假想入场权利金 = 两腿 bid 之和（空头按 bid 卖，账本约定）；`quotable` = 两腿都 `quote_ok`；
- **按账本自己的 `size_contracts` 与当时的 `nav_for_sizing` 算出的张数**（记下用的 NAV）；
- 入场时点状态的特征快照：该票历史财报涨跌（只取财报日早于入场日的）、跨式 / 宽跨各自的带外次数 k/n、权利金比、点差——
  **点时点**，日后做任何特征分析都不会读到事后才有的东西。

平仓时（跨式在账本里平仓的**同一天**）：对这两个符号重新报价，空头按 **ask** 买回；某腿没有 ask ⇒ 该腿取平仓日标的价下的内在价值
并标 `exit_basis="intrinsic"`；记 `pnl_per_share`、`pnl_usd`（按入场时记下的张数）。同日跨式用账本自己的平仓价。

## 3. 假设与统计量

- 配对单位 = 一笔**空头**跨式及其影子宽跨（多头单位只描述、不检验——用户关心的是卖方；多头宽跨是另一个问题）。
- 度量：`d_i = (宽跨_pnl_usd − 跨式_pnl_usd) ÷ NAV_i`（各自按账本定仓规则的张数；NAV_i = 入场时的 `nav_for_sizing`）。
  即「账本若改交易宽跨，这一笔会多赚 / 少赚多少 NAV」。**含定仓杠杆**——这是刻意的，它正是切换时会发生的事。
- 统计量：`D = mean(d_i)`。H0：`d_i` 的分布关于 0 对称（结构不造成系统差异）。H1（双侧）：`D ≠ 0`。

## 4. 独立单位、过滤与排除（全部事前可知，不看结果）

1. 单位 = `(ticker, earnings_date)` 对应的那笔空头跨式；同一事件只有一笔。
2. 必须**入场当天带着影子记录**（≥ 部署日）；登记前入场的一律排除（§0）。
3. 影子宽跨入场时 `quotable = True` 才进检验；**不可成交的比例单独如实报告**（它本身就是「宽跨在这个账本里做得了多少」的答案），
   不往后找别的行权价顶替。
4. 已结算 = 账本已平仓；用同一个平仓日的两个结构。`written_off`（核销）的单位两边都按账本口径，不单独处理。
5. 不用点差闸门筛宽跨腿（账本对 ATM 腿的 15% 闸门只管「要不要开仓」；宽跨的点差已经体现在「按 bid 卖、按 ask 买回」里）。

## 5. 置换

- 分块 = 财报日所在 ISO 周；**块内所有单位共用一个符号**（同周事件被同一轮行情推着走，单位层面翻符号会低估方差——本仓「横截面池化」教训）。
- 符号翻转：块数 ≤ 16 ⇒ 枚举全部 `2^块数`；否则随机 20000 次，`seed = 20261021`。
- `p = #{|D_perm| ≥ |D_obs|} ÷ 总数`（含自身，并列算「≥」，保守）。

## 6. α、就绪闸与判定

- 单个检验，双侧，α = 0.05。**只在就绪后跑一次**，不做中期偷看。
- 就绪（同时满足）：有效单位 ≥ 30、块数 ≥ 8（块数 b 时双侧 p 的下限是 2 ÷ 2^b：b = 8 ⇒ 0.0078 < 0.05）。
  门槛是「置换分布不至于太抖」的启发式，**不是功效计算**；按目前一个季度只有个位数到十几笔空头开仓，**达标可能要半年以上（待验证）**。
  够不着就是如实的「无法检验」，不是放宽闸门的理由。
- 判定：`p ≤ 0.05` ⇒ `reject_h0`，并报 `D` 的符号；否则 `fail_to_reject_h0`——**意思是「这个样本量下没看出差异」，不是「两者一样」；
  现状（卖 ATM 跨式）不变。**

## 7. 盲化（行为规则）

- 代码保证：`progress()` 只返回计数（已记录 / 可成交 / 已平仓 / 块数）；`run_once()` 未就绪时拒绝运行；冻结前没有任何代码路径把同一笔的
  宽跨盈亏与跨式盈亏放在同一个返回值里。
- 信息论上盲不了：影子记录与账本平仓记录都在文件里。**冻结之前从任何出口把某笔的影子宽跨盈亏和它的跨式盈亏拼在一起看 = 偷看 = 协议变更（§8）**，
  包括「随手看看几个例子」「T 那一笔」。
- 页面：Alpha Bot 跨式页只显示影子记录进度（计数）；持仓卡与已平仓表**不**显示任何一笔的影子盈亏。
  入场时的「跨式 vs 宽跨」对比卡是入场时点的事实（报价、点差、历史），不含结果，照常显示。
- 冻结：`/usr/local/bin/python3 straddle_strangle_shadow.py --run-once`，结果写 `<数据根>/options_paper_state/straddle_strangle_shadow_result.json`
  （`os.link` 先到者赢，不覆盖）。删改它 = 协议变更。

（变更前的单位是否还进检验；默认不进）。修 bug（实现与本文不符）不算协议变更，但同样要记修订并说明受影响的行。

## 9. 本协议**不**回答什么（以及选择规则怎么办）

- **不检验任何「按标的选结构」的规则。** 单只票 ≤ 8 次历史、整个检验才几十个单位，特征 × 结果的交互项功效几乎为零；
  在已经看过 T 的情况下现拟一条规则就是拟合个例。§2 的特征快照是为将来留的：若 §6 拒绝 H0，**再另写一份预注册**，
  规则在看任何「特征 × 结果」之前冻结，并如实评估样本够不够。
- 不回答「宽跨本身赚不赚钱」（只比较两个结构）；不回答「更宽的行权价 / 别的 delta」（只取 25Δ 一档）；
  不回答「用等量张数 / 等 vega 比较」——这些作**描述性**旁证（§11），不出 p 值。
- 只覆盖被账本开仓的单位（受 `max_open`、点差闸门、信号标签约束），外推到别的入场方式要小心。

## 10. 实现计划（批准后；每一步都要有会红的守卫）

1. `earnings_vol_signal`：信号行记 `strangle_quote`（c25 / p25 的简报 + 历史涨跌快照），**在 `compute_signal` 返回之后挂上**（同 `gex_ctx` / `shadow_event`
   的结构：判断路径碰不到它）；AST 守卫：`compute_signal` / 账本开仓判断路径不读它。
2. `options_paper_leg`：开仓时把它抄进持仓的 `shadow_strangle`，按账本 `size_contracts` 算张数并记 `nav_for_sizing`；平仓时对两个符号加一次报价
   （try / except，失败**不影响**账本自己的平仓，但在源头登记失败 ⇒ status.json ⇒ P2，不静默）。
3. 新模块 `straddle_strangle_shadow.py`（仿 `straddle_gex_prereg.py`）：`PREREG` 常量、`progress()`、`run_once()`、块符号翻转。
4. Alpha Bot：跨式页底部加进度面板（只计数）。
5. 守卫：**行为差分**（同一输入有 / 无影子，账本的开仓、张数、现金、平仓逐项相同）；影子读取失败不改账本；任何 API 不返回配对盈亏（键名 + 遍历）；
   部署日之前的单位不进 `progress()` 的分子。
6. 版本：这一步单独占号（本草案所在版本只含对比卡 + 本文，不含记录代码）。

## 11. 描述性旁证（不出 p 值、不参与判定）

按空头 / 多头分开：不可成交比例；`d_i` 的中位数与胜率；每股盈亏占现价 %（不含杠杆）的配对差；等量张数的 USD 配对差；
`exit_basis` 为 intrinsic 的比例；按入场时点差、权利金比、带外次数分层的计数（**只数个数，不看盈亏**，直到 §6 冻结之后）。

## 12. 已知局限

- 快照是收盘后的报价，25Δ 腿点差系统性偏宽（约盘中 2–3 倍，见 `earnings_vol_signal` 文件头）；影子记录和账本用同一份，所以结构之间可比，
  但绝对点差成本偏悲观。
- 平仓日跨式与宽跨用同一天，但两者的流动性在平仓日未必一样好；某腿无 ask 时用内在价值是近似。
- 账本按权利金定仓是**这个账本的**规则，不是宽跨的天然属性；换一种定仓（等 vega、等名义）结论可能不同——这正是 §9 把它列为不回答的原因。
- 财报时段（盘前 / 盘后）未观测，两日窗口同 GEX 预注册。
- 同周事件相关，分块只处理「周」这一层。
