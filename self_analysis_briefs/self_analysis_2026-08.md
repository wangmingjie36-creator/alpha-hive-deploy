#### 假说 3 · 期权情绪饱和分位（Oracle Saturation Percentile, OSP）

- **信号名称**：期权情绪饱和分位 / OSP
- **数据来源**：
  - 已有：`oracle_bee._analyze_term_structure()` / `_analyze_deep_skew()` / `_calc_max_pain()`（yfinance `Ticker.option_chain(exp)` 的 `impliedVolatility` / `openInterest` 字段）

- **计算方法**：
  ```python
  hist = oracle_scores(ticker)[-60:]           # 60 交易日滚动
  if len(hist) >= 30:
      pct = percentile_rank(today_oracle, hist)
      if   pct >= 0.90: adj = -0.8             # 情绪饱和 → 局部顶
      elif pct >= 0.75: adj = -0.3
      elif pct <= 0.10: adj = +0.4
      else:             adj = 0.0
      oracle_score = clamp(oracle_score + adj, 0, 10)
  ```
