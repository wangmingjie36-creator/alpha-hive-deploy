## [0.45.755] — 2026-11-09 — Fixed：CBOE 调整后 / 非标准 root 的合约（CVX1、B1VDA、B1SLA）不再被算进「OCC 符号解析失败（疑格式变更）」告警——剔除行为一点没变，只改告警定性
<!-- 认领：claude/occ-nonstd-root 2026-11-09T12:39:52-07:00 ccdfeeb0 -->

**起因（用户 2026-11-09 定：让它不再把调整后的 root 算进「疑格式变更」）。** CVX 的 64 个合约代码全以 `CVX1` 开头、全是 2027-01-15 到期——
原赫斯（HES）期权，雪佛龙收购后 OCC 改成调整后符号，占 CVX 未平仓 0.40%（11-09 用当天 CBOE 数据重新核对：1188 个合约、64 个失败、占 OI 2,178 / 540,558）。
旧告警按**合约个数**比 5%，CVX 总合约数低于约 1280 的日子（11-09 是 5.39%）天天响「疑格式变更」；NVDA 的 `B1VDA`（180 个）、TSLA 的 `B1SLA`（240 个）
11-05 起出现（疑为 NYSE 二元期权，是不是待验证），也在 4% 附近逼近同一条线。这些都是误报，真有 CBOE 格式回归时反而淹在里面。

### Fixed
- `cboe_options.py`：
  - 新 `_OCC_ANY_ROOT` / `_nonstandard_root(sym)`：`_parse_occ` 失败的符号里，**形状仍是 OCC、只是 root 带数字**（且日期合法）的认出 root；真畸形（缺字段、行权价不是 8 位、日期不合法、小写）返回 None。
  - 新 `_report_unparseable(ticker, options, dropped, fmt)`，`fetch_cboe_chain`（主链）与 `fetch_cboe_raw_contracts`（卖权选择器的原始合约）两处共用：
    - 真畸形的合约仍按旧阈值（> 5% 的合约个数）、**旧措辞**报「疑格式变更」，个数只数真畸形；
    - 非标准 root 的合约另算：占全链未平仓 > 5%（`_NONSTD_ROOT_OI_WARN`）⇒ WARNING「口径受影响」（剔除开始改变口径，留着一根会红的线）；否则每进程每个 (标的, root 集合) 只记一行 INFO（点出 root、个数、占 OI 比例）。
  - **没变的**：`_OCC` / `_parse_occ` 一个字符没动；被剔除的合约、`contracts` / 主链结果、`n_dropped_unparseable`（卖权账本按它记 `fetch_counts`）全部逐位不变。
- ⚠️ **不要为收 CVX1 放宽 `_OCC`**：`_parse_occ` 返回 `(expiry, cp, strike)`、丢掉 root，没人校验 root == 标的。放宽后 CVX1 按 100 股混进 CVX（实际交割物不同，同到期同行权价深度实值认购贵约 $5），
  B1 二元期权会被当成 NVDA / TSLA 的正股期权。「root 不认数字」是现在唯一挡住它们的东西。

### Added
- `tests/test_cboe_nonstandard_root.py`（22 条）：分类函数（CVX1 / B1VDA / AAPL1 认出；日期不合法的带数字 root、7 位行权价、小写、标准符号都不算）+ `_parse_occ` 仍拒绝 CVX1；
  CVX 11-09 形状（64/1188、OI 0.40%）两条路径都不再报「疑格式变更」、各一行 INFO；剔除不变（带与不带 CVX1 的主链结果逐项相同）；INFO 每进程每标的一次；
  真畸形照旧报且只数真畸形（84/…，措辞同旧版）；占比 > 5% 报 WARNING、刚好低于线只记 INFO。
  已做 6 个变异，全红：不分类 / 占比线失效 / 去掉去重 / 放宽 `_OCC` / 畸形阈值降到 1% / 分类不校验日期。

### 验证
- 相关测试 540 条（指纹守卫 `test_signal_code_fingerprints` / `test_dim_ic_forward_test` 在内）+ 其余 6 个 CBOE 测试文件 192 条通过；`price.fields` 等输入层指纹**没有变红**（不需要登记）。
- 没做 / 待验证：非标准 root 究竟是什么产品（B1VDA / B1SLA 疑为 NYSE 二元期权）；`cboe_fetcher.py:393` 等其余走 `_parse_occ` 的地方本来就静默剔除、没有告警，这次没碰。
