### 起因

用户 2026-11-20 先在对话里查了「这几天从英伟达流出的钱去了哪」：东方财富的个股资金流（大单 / 超大单 vs 中小单）+ ETFdb 上 SMH / SOXX / XLP / XLV 的每日申赎，结论是「主力在卖、散户在接；钱没有离开科技、防御板块也没接住」。随后问「能不能放进 Alpha Bot」，看过方案后定范围：**个股 + ETF 资金流都要**。

### 数据源是实测后定的（两条都免费、不调 LLM）

- **个股**：东方财富日线资金流接口（`push2his…/fflow/daykline`），一只票一个请求、一次 30 天。⚠️ 实测**走代理会被对方断开**（`RemoteDisconnected`），直连通 ⇒ 这一条固定直连（Alpha Bot 启动时会给本进程设代理变量，`outbound.py`）。市场代码 105 / 106 / 107 逐个试、试中的记在内存。字段含义经「主力 = 超大单 + 大单」逐行核对（11-19 NVDA：−923 万 = −9509 万 + 8586 万），对不上整份拒收。
- **ETF**：方案里原想用 ETFdb（对话里就是从它的页面图表读的），实测对程序请求回 **403**；iShares 的数据下载对程序回 403 / 只回网页，VanEck 的接口只给「今天的」份额。改用**道富官网每只 SPDR 的净值历史 xlsx**（逐日净值 + 流通份额，几千行）：资金流 = 份额变化 × 当天净值，与 ETFdb 同一算法——11-18 XLP 本式 −4.29 亿美元、ETFdb −4.30 亿。代价：**只有道富的基金**，所以收 SPY + 11 只板块 SPDR（同「板块」页名单），**SMH / SOXX 不收**，页面与帮助页写明。

### Added
