## [0.45.798] — 2026-11-20 — Fixed：Alpha Bot 对比页的 OI / P/C 变化与提示改为在「同一批合约」上比（全链口径跟着现价过滤，大跌大涨时假跳）
<!-- 认领：feat/compare-same-grid-oi 2026-11-20T12:58:44-07:00 d2690a8f -->

### 起因

用户 11-20 问「扫描记的全链 OI 和 CBOE 整条链对不上，正常吗」。查明口径是故意的：`full_chain_oi` 只收行权价在 **[0.60×现价, 1.45×现价]** 之内、**前 24 个到期日**的合约（`cboe_options.fetch_cboe_full_chain_oi` 与 yfinance 路径同口径；按此规则用 11-20 的链重算 NVDA put 675 万，扫描记 691 万，差额是 OI 晚一天与所用现价）。但这个窗口**跟着现价走**：同一份 NVDA 链、OI 一张不动，只把现价从 145.98 换成 130.35，put 675 万 → 602 万、call 559 万 → 354 万，P/C 1.21 → 1.70。对比页 v0.45.759 认定「全链两项日间可比」，变化与提示都用它；NVDA 11 月单日 −5%～−10% 的行情里，这两项的跳变大半是合约进出窗口，再叠加月度到期日当天到期的合约下一次消失（11-20 到期的 put 约 74.5 万张）。

### Fixed / Changed

- `alphabot/options_compare.py`：
  - `day_view` 新增 `oi_grid`：扫描记的逐合约未平仓 `full_chain_oi.{call,put}_exp_oi` 读成 `{到期日: (行权价数组, OI 数组)}`（`array('d')`：服务端按天缓存读数，存成 dict 套 dict 一天约 2.7 MB、回看 31 天 80 多 MB；数组约 1.3 MB / 天）。一侧缺表 ⇒ None；坏格子丢掉。
  - `same_grid`（纯）：只数两天都覆盖到的格子——到期日取两天都有的，行权价取两天各自出现过的范围的交集，范围内某天没记的格子按 0（扫描只收 OI > 0）。给两天各自的 Call / Put、P/C、变化百分比、这批合约占各自全链的比例。任一天没有逐合约表 ⇒ `no_oi_detail`；两天没有重叠 ⇒ 新原因码 `no_common_grid`。**不退回全链总量**。
  - `compare` 新增 `grid` / `grid_oi_pct` / `grid_pc_ratio`；`full_oi_pct` / `full_pc_ratio` 照旧给出（表面变化），但**提示（`alerts`）只看 grid 两项**，提示文字写「同一批合约上 …」。`readings` 的变化同样改用 grid，并写明是哪批合约（行权价范围、到期日个数）；比不了就写为什么。`METRIC_READS` 两条说明改写。
  - `public_view`：给页面的读数去掉 `oi_grid`（`build_ticker` 的 today / prev、深度页 `deep_report._options` 都经它出）。
- `alphabot/deep_report.py`：期权读数改经 `OC.public_view` 出（否则逐合约数组会进深度页的 JSON）。
- `alphabot/static/pages/compare.js`：总览列、详情 KPI 的 P/C 与 OI 变化改读 `grid_*`，KPI 写明「同一批合约 lo–hi、N 个到期日」；近端窗口说明、OI 趋势图标题补「全链也有窗口」。
- `alphabot/static/pages/help.js`：对比页「全链 P/C / 全链 OI」两条与阈值说明改成同一批合约口径。
- `tests/test_alphabot_options_compare.py`：夹具 `_res` 带逐合约表（`grid="auto"` 与 `fcall` / `fput` 一致，`None` = 旧记录）；阈值用例改由 put 数驱动；+6 条：现价窗口移动（全链 P/C 0.57 → 1.75、同一批合约不动）不提示且同一批合约真变了照样提示；当天到期 / 新挂到期日不算变化；没有逐合约表不退回全链、解读写原因；两天没重叠；坏格子与缺一侧；页面与深度页 JSON 里没有 `oi_grid`。纯度白名单加标准库 `array`。
- `tests/test_alphabot_flow_story.py`：逐项解读的 P/C 变化改为同一批合约口径（文字带合约范围）。
- `alphabot/CLAUDE.md`：对比页子条改为同一批合约口径。
- `tests/_must_run.json`：`make test-changed` 报 16 个测试文件读了登记表没有的非代码文件（多数与本版无关，是登记表落后），照提示 `--update` 并入（只并不删）。

### 已核对 / 未核对

- 真数据（10–11 月扫描结果，只读）：11-04 → 11-05（NVDA −9.3% 那天）全部标的里 OI / P/C 挂提示的从 6 只降到 1 只；11-12 → 11-13 从 3 只到 0 只；11-18 → 11-19 都是 1 只。NVDA 11-09 → 11-10：全链 OI +0.9%，同一批合约 +8.4%（上一次 11-09 当天到期的 17 万张与 250 以上被挤出窗口的 call 都不算），覆盖今天全链的 98.4%。
- **未核对**：提示阈值（OI ±15%、P/C ±0.25）照旧是旧对比任务的经验值，换了口径后没有重新标定；历史趋势图仍画全链总量（逐日两两对齐不适用于整条曲线），只在标题上写明会假跳。
