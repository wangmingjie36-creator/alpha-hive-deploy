### Fixed
- `options_paper_leg.py`：平仓此前挂在盯市的 `ok = _quote_ok(call) and _quote_ok(put)` 上（要 bid>0 且 mid>0）。账本的成交约定本来就是镜像（short 按 ask 买回，`exit_fills`），**平仓并不需要 mid**。一条深度虚值腿 bid=0 ⇒ 整个平仓被挡死、未到期一律等（NVDA 空跨式 2026-11-18 / 19：入 10-21、行权价 222.5、到期 11-20，看涨腿 bid=0，`mark_source=stale`，`unrealized` 两天不动）。
  - 新 `_exit_executable(side, qc, qp)`：每条腿要么 `_quote_ok`，要么（**仅 short**）「bid 恰为 0 且 ask 有限 > 0」（`_bid_zero_ask_only`）。两腿都可成交 ⇒ 按 `exit_fills`（ask）平仓。两腿都 `quote_ok` ⇒ 与此前逐字节相同。
  - **没有 ask（None / 0 / 负）、bid 缺失 / 负 / 布尔、ask<bid 倒挂、整条腿无报价 ⇒ 不可成交，照旧等待**：不取 ask/2、不按 0 估、不拿内在价值提前平（v0.45.449 的口径不变）。long 的 bid=0 腿不动（现行规则 `trade_cheap=False` 不开 long，成交价 0 的语义另议）。
  - **`_quote_ok` 一字不动**：盯市与入场的点差口径建在它上面；`bid_zero_greeks_usable`（对冲账本的 Greeks 判据）也不碰，这里不需要 Greeks。
  - 平仓记录新增 `exit_bid0_legs`（按 ask 买回的 bid=0 腿，如 `["call"]`；无则整键省略、旧记录逐字节不变），`rationale` 追加一句。**`mark_source` 不加新值**（成交约定没变）⇒ 影子宽跨的 `_attach_shadow_exit` / `exit_record` 都不用动，也不会落到 `ledger_<basis>` 的 `unpriced`。
- **观测点**：此前「该平仓但报价不可用」只写一行 INFO、没人看得见。现在该平仓却没有可成交的价 ⇒ 仓位记 `exit_blocked_since`（这一段连续平不了的第一天）/ `exit_blocked_reason`（哪条腿、`bid=… ask=…`，无则整键省略），`run_for_date` 返回 `exit_blocked`，日报小节加一条「该平仓却没有可成交的价」，连续第二个日历日起日志升 WARNING。
