### Added
- `alphabot/zg_decompose.py`（新，纯函数；不 import 卖权模块，`view_contracts` / `zero_gamma_sweep` / `strike_profile` 由 service 注入）：
  - 合约按 OCC 代码对齐（没有代码用 到期日 / 行权价 / C·P）。混合链先按「合约集合」那一天的链与视图定下收哪些合约，每张合约的 oi / iv / dte 各取所选那天的值；新挂牌 / 已到期的合约用自己那天的值，影响整个归「合约集合」。混了别天 IV / T 的行去掉 CBOE gamma。
  - **两个方向各换一遍**：从昨天出发每次只换一项成今天的、从今天出发每次只换回一项。两边是同一项且各走完总距离的 `dominant_share` 以上 ⇒「主因明确」；同一项但不够 ⇒「有主导项，但不独占」；两边不同 ⇒「各项交互，分不开」；总移动 < `flat_pct` ⇒「基本没动」。
  - 记的是**状态**（最近零点 / 全段为正 / 全段为负）而不是数：Zero Gamma 可以不存在，不做 Shapley 平均分摊。状态不同 ⇒ 距离 `STATE_GAP`（大于 ±20% 窗口内任何零点移动）。
  - 高亮：曲线状态变了、现价处符号翻了，或两天都过零且最近零点移动 ≥ 现价 2%。阈值是拍的、未经检验，只控制显示，不进任何决策。下一到期视图换了到期日 ⇒ 标 `expiry_rolled` 并提示优先看 ≤45 天视图。
  - 逐行权价 OI 归因：今天视图内两天都有的合约，只把 OI 换回昨天，列净 GEX 变化最大的几档（现价 ±12% 内）及 call / put OI 变化。
  - 规则常量唯一在 `RULES`，经 `/api/method` 的 `zg_decompose` 给页面与帮助页。
- `alphabot/service.py`：`chain_archive_dates`、`zg_decompose(ticker, date=None)`：缺省取最新一份存档、配它之前最近的一份；交易日历算隔了几个交易日（判不了写 None + 日志）；`no_current_archive` / `no_previous_archive` / `archive_missing` / `archive_corrupt`（附 `bad_date`、异常）/ `exception:…` 各报各的，不装成「没动」；算不出计 `stats.zg_decompose_failures` + 日志 warning。结果按两份文件的修改时刻缓存在内存，存档被覆盖就重算。**不新增落盘文件，不调任何 API。**
- `alphabot/server.py`：`GET /api/zg-decompose/{T}?date=`。
- `alphabot/static/pages/zg_decomp.js`（新）+ `ticker.js`：「水平」子页 Gamma 曲线下方加「Zero Gamma 日间拆解」卡片，随期限视图切换；单换后与出发点相同的格子写「（没动）」。
