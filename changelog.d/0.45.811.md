## [0.45.811] — 2026-11-23 — Fixed：对冲账本里已过到期日、等结算的跨式腿 Greeks 也记 0（结算推迟时不再判「缺报价」整轮不对冲）
<!-- 认领：claude/hedge-expired-unsettled 2026-11-23T12:59:00-07:00 88e11969 -->

### 起因

v0.45.803 只管「到期日当晚」（as_of == 到期日、S 是这一场收盘）。跨式账本在**下一个扫描日**才结算到期的腿，而且结算可以推迟（例如 TD 收盘价滞后）——推迟期间腿仍在持仓里、dte < 0。这时 CBOE 链上已经没有这张合约（或只剩清零的占位），`option_exposures` 判「缺报价」⇒ 整组 β·$Delta unknown ⇒ 当天不对冲，和 11-20 那条黄条是同一个形状。

### Fixed

- `portfolio_greeks.option_exposures`：`dte < 0` 的腿（已过到期日、还没结算掉）**不看报价、不要收盘价**，Greeks 全 0、`mid=None`（锁定价是到期那一场的收盘，当天的 S 不是它，不另算），行上标 `expiry_intrinsic=True` 与 `expired_days`。dte == 0 的规则（803）不变。
- 文字随之改：日报覆盖行「当天到期或已到期待结算的腿已按到期收盘锁定」；对冲页 `hedge.js` 黄条、跨式页 `straddle.js` 说明行同步改写。压力表照旧剔除：已过到期日的腿沿用原来的 `option:expired Nd` 标签（`stress_table` 按 dte 选标签），只有当天到期那种写 `option:expiry-day intrinsic`——第一版把过期腿也改成了 803 的标签，被既有测试 `test_portfolio_greeks.py::test_expired_contract_excluded_not_repriced` 抓到。
- `tests/test_portfolio_greeks_expiry_intrinsic.py`：更新 803 的文字断言；新增 `TestExpiredUnsettled`（到期后第 3 天：Greeks 0、`expired_days` 3、不 partial；没有收盘价 / 报价可用都照样记 0；压力表剔除；跨式页点名两条腿）。共 24 条。
