## [0.45.769] — 2026-11-11 — Alpha Bot 深度页加异动成交按到期日分层与 VIX 期限结构说明、对比页加逐项解读（只写算得出的结论）

用户 2026-11-11 指出深度页缺了旧深度报告的解说，贴了三处：对比页那排数字没有解读、VIX 期限结构说明、异常期权流按到期日的逐层分析。
三处在旧报告里都是按规则从数据算的，原料在现在的扫描结果里都在 ⇒ 不调 LLM、不花钱就能做回来。

**这一版部分收回了 v0.45.760「只搬数字与事实、不搬推断句」那条**（用户同日同意的新分法）：
- **写**：能从记录直接算出来的量——倍数、占比、行权价范围、与上一层 / 上一次的差，以及固定的「这个数怎么读」；
- **不写**：数据支持不了的判断（旧报告里的「鲸鱼式定向押注」「市场信念高度集中」「卖方策略有利」），以及数据没取到时的任何结论。
  旧报告的两处反例：VIX 那句在「M1=N/A → M2=N/A」时仍给出「正价差」并接着讲卖方策略；异动流那段把 115 美元宽的行权区间说成「极窄」。

### Added
- `alphabot/options_compare.py::flow_by_expiry`（纯函数）：异动成交按到期日分层——两侧笔数 / 权利金、占全部异动权利金的比例、
  哪一侧的钱多（`lean`：只有 / 为主 / 偏 / 两边接近，阈值在 `RULES`）、金额最大的几笔、几条算出来的说明（`facts`）。
  `day_view` 纯新增 `flow_expiries`。⚠️ **不把 Call 多写成看涨**：记录里的 `bullish` 只是按 Call / Put 贴的（近 12 个扫描日 8570 笔里
  call ⇒ True、put ⇒ False 无一例外），不知道是买入还是卖出。判不出两侧 / 缺到期日的计 `unclassified`，没有权利金金额的计 `missing_premium`。
- `alphabot/options_compare.py::readings` + `METRIC_READS`：对比页每个读数的「现在 / 和上一次比 / 怎么读」；`build_ticker` 纯新增 `readings`。
  只陈述量的变化（「Put 相对 Call 变多了」），不解读方向；取不到是 None。
- `alphabot/deep_report.py::VIX_TERM_READS`：VIX 期限结构标签 → 展示名与「这个形态是什么」；`_macro` 纯新增 `vix_term_zh` / `vix_term_read` /
  `vix_term_source`。扫描只记标签、不记两个月份的点位 ⇒ 页面不写点位与价差；`unknown` / 缺失 / 不认识的标签都不给结论。
- `alphabot/static/pages/deep.js`：「期权要点」里加「异动成交按到期日」（`flowLayers`），「人气与板块」末尾加 VIX 期限结构一段（`vixTerm`）。
  `compare.js`：单票详情加「逐项解读」表。`alphabot.css` 加 `.flow-layer`。帮助页两节各补说明。
- `tests/test_alphabot_flow_story.py`（新，19 条，全离线）。
