## [0.45.756] — 2026-11-09 — Removed：退役 `crowding_detector.get_crowding_metrics` 与该文件的 `__main__` 示例（生产零调用；取数失败时把量比填 1.0、动量 / 波动率填 0.0、均量填 0）
<!-- 认领：main 2026-11-09T13:40:09-07:00 23fe9c9a -->

**起因**：v0.45.754 全仓搜「量比硬编码 1.0」时只剩这一处。用户 2026-11-09 定清掉。

**为什么是整段退役、不是改成 None**：这个函数唯一的调用者是 `crowding_detector.py` 自己的 `__main__` 示例（`yf_daily.SOURCES` 登记里也写明「生产只被它自己的 __main__ 调用」）。生产里 Scout / Guard 直接调 `real_data_sources.get_real_crowding_metrics`，喂的是蜂群已取好的 `stock`。它的假值不止量比：
- 正常分支：均量 ≤ 0 ⇒ `volume_ratio` 1.0；不足 5 根 ⇒ `momentum_5d` 0.0；`volatility_20d` 先填 0.0，不足 20 根就留着；
- 异常分支：`{"price": 0.0, "momentum_5d": 0.0, "avg_volume": 0, "volume_ratio": 1.0, "volatility_20d": 0.0}`。
逐个改成 None 等于给一段没人用的代码做维护，所以直接删。

### Removed
- `crowding_detector.py`：`get_crowding_metrics` 与 `if __name__ == "__main__"` 示例删除，原位置留注释说明；随之不再用到的 `import math as _math` 删除。`CrowdingDetector` 类不动（Scout / Guard / Rival 在用）。
- `yf_daily.py`：调用方登记 `SOURCES` 删去 `crowding_cli`（唯一用它的调用点随函数删了）。

### Changed
- `tests/test_yf_daily.py`：入口策略表 `POLICY` 删去 `("crowding_detector.py", "get_crowding_metrics")`（登记表与实际调用点双向对账，两边一起删）。
- `tests/test_momentum_window_alignment.py::test_full_history_formulas`：动量全历史公式扫描原断言「`price_metrics.py` 与 `crowding_detector.py` 都有」，crowding 那份副本随函数删了，改为只要求 `price_metrics.py`。

`experiments/silent_degradation_audit_verified.json` 里提到 `get_crowding_metrics` 的是历史审计记录，未改。
