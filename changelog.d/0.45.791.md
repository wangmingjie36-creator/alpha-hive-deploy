## [0.45.791] — 2026-11-20 — Removed：弃用并删除 alpha-hive-web 订阅落地页（Next.js + Stripe，已闲置）
<!-- 认领：chore/retire-alpha-hive-web 2026-11-20T08:36:23-07:00 24b26492 -->

### 起因

`alpha-hive-web/` 是 2026-03 做的订阅落地页：首页填邮箱，跳到 Stripe Checkout 付款，部署在 Vercel。2026-03-23 之后代码就没再动过；`.env.local` 里只有 Stripe 测试密钥，从来没收过真钱。v0.45.389（2026-09-30）又因为 Vercel 每次构建都失败，关掉了自动部署。用户 2026-11-20 确认不再使用，决定弃用。

### Removed

- `alpha-hive-web/` 整个目录（16 个被跟踪的文件）。没被跟踪的部分（`node_modules/`、`.next/`、`.vercel/`、只含 Stripe 测试密钥的 `.env.local`）挪进了废纸篓 `~/.Trash/alpha-hive-web-retired-2026-11-20`，没有直接删除。
- 要恢复：`git checkout 83c1e654 -- alpha-hive-web`。Next 16 升级版在分支 `chore/next-16` 的 `ff45e1f5`。

### 刻意没动

- 根目录的 `vercel.json`（`git.deploymentEnabled=false`）**暂时保留**。Vercel 项目和 GitHub 集成要用户在 Vercel 后台删除，删除之前这个文件负责挡住注定失败的构建，提前删掉会让 PR 上重新挂红色的 Vercel 状态。用户在后台删完之后，再单独删它，以及 `data_backup/migrate_data_root.py` 里 `vercel.json` 的分类条目。
- `data_backup/migrate_data_root.py` 的 `"alpha-hive-web"` 分类条目：它给旧检出里的磁盘目录分类，留着无害；删掉的话，还留着这个目录的旧检出跑 check-old 会报 UNKNOWN。
- `.gitignore` 的注释、`tests/test_no_data_tracked_in_git.py`、`tests/test_root_data_guard.py` 里的 `alpha-hive-web/...` 路径都是虚构的示例路径，用来测忽略规则和数据闸，不要求目录存在。
- `tests/_must_run.json` 里 `alpha-hive-web/*` 的登记行：这个登记表是整套测试实测生成的，下次 `--update` 时自然会刷新，不手改。
