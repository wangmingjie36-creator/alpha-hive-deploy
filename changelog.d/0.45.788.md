## [0.45.788] — 2026-11-20 — Fixed：CBOE 延迟行情接口迁到 cdn-api.cboe.com 后不带 Referer 一律 403，全部 CBOE 请求补上 `Referer: https://www.cboe.com/`
<!-- 认领：claude/cboe-referer 2026-11-20T08:01:05-07:00 30a57fa9 -->

### 起因

2026-11-20 早上 Alpha Bot 标的页显示「这只标的现在拿不到期权链 · CBOE 取数失败（网络不通或文件不可达）」。`alpha_hive.log` 从 11-19 20:05（本机）起，NVDA / TSLA / META / AMZN / NVDL 每次都是 `CBOE 拉取 … 失败（重试 3 次耗尽）：HTTP Error 403: Forbidden`。v0.45.786 的会话在 11-19 晚上也撞到了同一个 307 → 403。

11-20 用 curl 实测：
- `cdn.cboe.com/api/global/delayed_quotes/*`（期权链、`_VIX` 报价）现在 **307 跳到 `cdn-api.cboe.com`**，新域名前面是 Cloudflare，返回 "Sorry, you have been blocked"。走代理和直连结果一样，所以不是出口 IP 被封。
- 逐个请求头试：只换完整的浏览器 UA 仍是 403，只加 `Origin` 也是 403；**加 `Referer: https://www.cboe.com/` 就是 200**，`Mozilla/5.0` 这个 UA 也能过。
- `us_indices/*_History.csv`（VIX / SKEW / VVIX 历史）不受影响，带不带 Referer 都是 200。
- 根路径 `cdn.cboe.com/` 现在也回 403。编排器、`alphabot/outbound.py`、`llm_shadow_daily.py` 的网络探活都把 4xx 当作「隧道通了」，所以不受影响、没有改。

### Fixed

- `cboe_options.py`：`_CBOE_HEADERS` 加上 `Referer: https://www.cboe.com/`。全部 CBOE 下载只走两条路：`_fetch_cboe_payload`（期权链）和 `fetch_cboe_bytes`（cboe_vix 的历史 CSV 与 `_VIX` 报价、cboe_fetcher 的 SKEW / VVIX、close_correction 的收盘印证），两条都用这份常量，改这一处就全覆盖。**不改域名**：urllib 对 GET 自动跟随 307，并且带上原来的请求头，实测能拿到完整的链；改域名还会牵动另外几处写死的地址，等 CBOE 真撤掉跳转再改。

### Changed

- `signal_code_fingerprints.py`：`_CBOE_HEADERS` 在 `price.fields` 的依赖闭包里，所以指纹变成 `3854255751b3e0d3`。**用户 2026-11-20 在对话里选 `no_value_change`**，不登记边界。依据：这次只改了放行条件，取到的文件和解析结果都不变——11-20 盘中经生产路径取 SPY，旧域名跟随跳转与新域名直取两份的 data 段 SHA-256 相同（12766 个合约）；而且 403 是在 11-19 扫描（15:23 完成，CBOE 抓取 39 次全部成功）之后才开始的，没有哪个扫描日受影响。

### Added

- `tests/test_cboe_gzip.py::TestReferer`：两条下载路径（`_fetch_cboe_payload` / `fetch_cboe_bytes`）发出的请求都必须带 Referer。做过变异：去掉 Referer 后这里会红。`test_shared_header_dict_is_not_mutated` 里的常量期望值同步更新。

### 验证

- 修复后经生产代码路径真网络取数：SPY 12766 个合约、NVDA 4750 个（`last_trade_time` 是 11-20 09:49 ET），`_VIX` 报价 28.73，`failed=0`。
- 相关测试 132 条（`test_cboe_gzip` + `test_signal_code_fingerprints`）通过；ruff F821/F401 无报错。

### 未做 / 已知

- Alpha Bot 把 `payload_unavailable` 显示成「网络不通或文件不可达」，但这个原因码同时包含 403 被拒、空链、超时，页面上看不出是被拒绝了。本版没有拆分原因码。
- 正在运行的 Alpha Bot 进程用的是开发检出里的旧代码；这个修复合入、开发检出更新之后，要重启 Alpha Bot 才会生效。生产扫描则在推上 origin/main 之后的下一个扫描日自动快进。
- CBOE 收紧了接入规则，以后可能还会再变。
