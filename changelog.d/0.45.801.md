## [0.45.801] — 2026-11-20 — Added：Alpha Bot 接货页「此刻浮动」——现取 CBOE 报价，自动刷新每笔 put / call / 持股此刻的浮动盈亏与净值
<!-- 认领：claude/hedge-live-pnl 2026-11-20T14:38:41-07:00 d1fdd685 -->

### 起因

用户 11-20 在对冲页加了实时刷新（0.45.800）之后，要接货型卖 put 页也加一个。此前那页的数全是账本最近一次收盘盯市的（put 按当天收盘后的 mid），盘中看不到此刻卖出腿的浮盈浮亏。

### Added

- `alphabot/wheel.py`：`live_view` / `live_symbols`（纯函数，本模块仍不读文件、不联网）——账本持仓 × 每只票一份 `cboe_options.quote_held` 结果 ⇒ 每条卖出腿 此刻浮动 =（权利金 − 此刻 mid）× 100 × 张数、较收盘 =（收盘 mark − 此刻 mid）× …；持股 =（现价 − 接货价）× 股数；此刻净值 = 现金 + 持股市值 − 未到期腿 × mid × 100 × 张数——**与账本自己的 `sell_put_wheel._nav_estimate` 同一公式**，mid 用账本同一判据 `mark_of`。算不出来写原因码（唯一表 `LIVE_REASONS`：报价没取到 / 合约不在文件里 / 没有合格双边报价 / 没有标的现价），合计净值不给，**不拿收盘 mark 顶上**。
- `alphabot/service.py::wheel_live` + `GET /api/wheel/live?force=1`：每只有持仓的票串行取一份报价（注入接缝 `wheel_quote_fn`；缺省 `cboe_options.quote_held`，只持股、没有未到期合约的票改走 Yahoo 报价只取标的现价、标明来源）；按票缓存（盘中 90 秒 / 盘外 15 分钟，「立即刷新」至少隔 20 秒；CBOE 文件本身是延迟报价、进程缓存 120 秒，再短拿不到新数）；失败也按同样的 TTL 缓存（一只坏票不被每次重下）并计 `stats.wheel_live_failures`；演示模式不展示（同 `wheel()`）；注入了日线而没给报价函数 ⇒ 不出网（`no_fetcher`）。
- `alphabot/static/pages/wheel_live.js`：「当前持仓」下面的「此刻浮动」面板——此刻净值、此刻收益、较收盘变动、持仓合计浮动；逐条腿 / 持股列权利金或成本、收盘 mark、此刻 mid（含 bid / ask）、此刻浮动、较收盘变动；写明每只票报价取到的时刻与文件里的最后成交。盘中每 `refresh_sec`（服务端给，120 秒）续刷、盘外 15 分钟；「自动刷新」开关记在本机（缺省开）、「立即刷新」按钮。
- `alphabot/static/pages/wheel.js`：挂载面板；「持股浮动」列改名「持股浮动（收盘）」。`help.js` 接货页加「此刻浮动」一条；`.claude/rules/options-ledgers.md` 接货账本子条加指针。
- `tests/test_alphabot_wheel_live.py`（18 条）：口径（含与 `_nav_estimate` 逐分钱一致）；诚实状态（票没报价 / 合约缺 / bid 为 0 或 ask < bid / 持股无现价 / 原因码全登记）；服务端每票一份、缓存与最小间隔、失败缓存与计数、取数函数抛异常、不注入不出网、演示不读账本；路由与页面接线。

- 二次检查补：过了到期日、还没被扫描结算的腿（账本到期日当天不结、次一个扫描日才结，周末 / 扫描失败会挂几天）此前会被报成「报价文件里没有这张合约」——改记 `expired_unsettled`（等结算），仍不估值、合计净值不给；服务端把美东今天传给 `live_view(today=…)`。守卫 `test_expired_unsettled_leg_is_named_not_contract_missing`。
