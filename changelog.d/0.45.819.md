## [0.45.819] — 2026-11-25 — Added：日报加一个不按行权价过滤的近端 P/C（≤45 天全部到期日、OI 直接相加、不含当天到期；只展示，不进评分）
<!-- 认领：worktree-daily-pc-45d-unfiltered 2026-11-25T11:17:32-07:00 ab08be46 -->

### 起因

用户 11-25 问卦象 dashboard（market-hexagram）的 P/C 与 Alpha Hive 对不上，是不是 Alpha Hive 算错。查明三处是三个量：日报评分用的 `put_call_ratio`（主链 4 个到期日、行权价 0.3～1.7×现价、按 DTE 加权）、全链 P/C（前 24 个到期日、0.6～1.45×）、卦象（≤45 天全部到期日、不过滤行权价、不加权）。前两个的行权价窗口都跟着现价走，暴跌暴涨时 OI 一张不动读数也会跳（v0.45.798 实测 NVDA 1.21 → 1.70）。用户定：日报也加一个不划行权价窗口的读数。

### Added

- `cboe_options.py`：`PC_NEAR_WINDOW_DAYS = 45`；纯函数 `pc_near_unfiltered(options, base, window_days)`——到期日取距 `base` 1～45 个日历日的全部（**当天到期的不算**：扫描在收盘后跑，那批合约已经没了；这是与卦象口径唯一的差别），行权价不过滤，OI 直接相加；窗口内没有到期日或 call OI 为 0 ⇒ None（不是「中立」）。非标准 root（CVX1、B1 二元期权）沿用 `_parse_occ` 不认。`fetch_cboe_pc_near_unfiltered(ticker)`：复用 `_fetch_cboe_payload` 的进程缓存，日期基准取 payload 自己的成交日期；失败 / 陈旧文件 ⇒ None；快照模式读快照里的 `pc_near_unfiltered`。
- `options_analyzer.py`：分析结果新增 `pc_near_unfiltered`（`{ratio, put_oi, call_oi, expiries, window_days, base_date, source}` 或 None）。**只在主链来自 CBOE 时算**（payload 已在缓存里，零额外请求）；yfinance 链 / 样本链 ⇒ None。经 OracleBee 的 `{**result}` 进 `details`，评分不读它。
- `dashboard_renderer.py`：`_pc_near_unfiltered`（校验：ratio 须是有限非负数）与 `_pc_near_unfiltered_html`；深度板块「全链 OI 视图」卡片的「全链 P/C」下面加一行「不过滤行权价 0.75（≤45天 · 11 个到期日）」，悬停写明口径与「只展示，不进评分」。旧记录没有这个键 ⇒ 不显示。
- `tests/test_pc_near_unfiltered.py`（20 条）：远端行权价照算、OI 不加权；窗口 1～45 天边界；call OI 0 / 无到期日 ⇒ None；坏行与非标准 root 跳过；签名里没有现价；日期基准取 payload 成交日期；陈旧 / 失败 ⇒ None；只在 CBOE 链上算；**只展示守卫**（全仓按名字读它的只许 `cboe_options` / `options_analyzer` / `dashboard_renderer`）；渲染好值 / 坏值。

### 已核对
