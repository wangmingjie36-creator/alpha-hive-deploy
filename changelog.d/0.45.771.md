## [0.45.771] — 2026-11-11 — Alpha Bot 深度页加「做市商与大额成交」板块：做市商对冲方向与关键价位（写明假设）、大额成交的分布与隔日未平仓验证

用户 2026-11-11 要求「运用期权数据加入机构和做市商的动作分析」。数据里**没有成交方身份、没有买卖方向**，两者都不能直接读出来；
与用户对齐的做法：做市商一半在写明假设的前提下推算；「机构」不下身份与方向的结论，按规模讲「大额成交」并用隔日未平仓验证。

### Added
- `alphabot/options_compare.py::dealer_view`（纯函数）：把扫描记的 `gex_state`（全链口径）换成「对冲时会怎么交易」——方向、
  量级、翻转位、Call / Put 侧 gamma 最集中的行权价、gamma 最集中的到期日、与上一次扫描的变化。通篇前提 `DEALER_ASSUMPTION`
  （做市商净多 Call、净空 Put；个股上可能反过来；是推算不是观测），页面原文照搬、只说一次。
  量级的换算核过公式（`advanced_analyzer._notional_gex_per_strike`：净 GEX（百万美元）= Σ 股价 × 100 × gamma × 未平仓 ⇒
  **股价每变动 1 美元**要交易的股票金额）：÷ 股价 = 股数，× 股价 × 1% = 每 1% 的金额。不可得 ⇒ 全字段 None + 原因，不给结论。
- `alphabot/options_compare.py::big_trades`（纯函数）。「大额成交」= 一张合约当天的成交权利金 ≥ `RULES["big_premium_usd"]`（100 万美元）：
  ① 今天有几张、两侧金额、多少张的成交量超过当时的未平仓（至少一部分是新开的仓）；
  ② **上一次扫描的大额成交这一次还在不在**：未平仓隔夜才更新 ⇒ 用「这次未平仓 − 上次未平仓」对上次那张的成交量，同侧、同行权价、
     同到期日地对（`full_chain_oi.{call,put}_exp_oi`）。≥ 50% 大部分留下 / ≥ 10% 留下一部分 / 增减都不到 10% 基本没留下 /
     减少超过 10% 以平仓为主；已到期与对不上的单列，不当 0；
  ③ 全部到期日里未平仓增减最多的合约（不限于被标成异动的近端到期日）。
  限制 `BIG_TRADE_CAVEAT`（每条是一张合约当天的合计、不是一笔订单；不等于机构；看不到买卖方向），页面原文照搬。
- `alphabot/deep_report.py::build` 加 `prev` / `prev_date`，输出纯新增 `positioning`；`service.deep` 往回最多找 3 个扫描日取这只票上一次的记录。
- `alphabot/static/pages/deep.js::positioning`：新板块，排在「期权要点」之后。帮助页补一条。
- `tests/test_alphabot_positioning.py`（新，20 条，全离线）。

### Fixed（v0.45.769 的措辞，本版查出）
- **「笔」「单笔」不准确**：异动记录的每一条是一张合约当天的成交合计（权利金 = 当天成交量 × 最新价 × 100），不是一笔订单。
  769 的分层里写了「共 N 笔」「单笔 X 占…」⇒ 改成「个合约」，并在页面注明（数合约个数只许用「个」，「张」留给持仓量与成交量：`tests/test_alphabot.py::TestHelpPage::test_contract_count_is_never_labelled_as_zhang` 记着用户把「N 张合约」读成持仓张数的教训）。
- **「扫单」名不副实**：扫描的 `*_sweep` 判据是「成交量 ≥ 未平仓的 5 倍且 ≥ 200 手」，不是跨交易所扫单 ⇒ 展示名改「成交远超未平仓」
  （`FLOW_TYPE_ZH`；扫描侧的类型名没动）。

### Fixed（既有问题，用户同日要求一并处理）
- **趋势图悬停提示被本站 CSP 拦掉样式**：ECharts 自带的提示排版（缺省 formatter / `valueFormatter` / `p.marker`）整段是行内 `style=`，
  被 `style-src 'self'` 拦掉 ⇒ 色点没了、名字和数值挤在一起（「全链0.99」），每悬停一次控制台报一串错。
  `charts.js`：`lines` / `columns` / `payoff` 的提示改成自己排版（`axisTip` / `dot`，只用样式类）；色点颜色放 `data-c`，
  `mount` 里的 MutationObserver 经 CSSOM 涂上（脚本设 style 不受行内样式限制），图释放时断开。`alphabot.css` 加 `.tip-dot` / `.tip-name`。
  测试钉住 `charts.js` 里不再出现 `valueFormatter` / `.marker` / `style=`，且每个 `tooltip` 都带自己的 `formatter`。
  实测（对比页 P/C 图悬停）：两个色点按系列色显示，CSP 违规 0 次。

  下一次扫描才看得到」（用户同日要求补）。页面没有另外算两次扫描之间隔了几个交易日。
