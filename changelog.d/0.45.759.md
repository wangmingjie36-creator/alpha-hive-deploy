## [0.45.759] — 2026-11-11 — Alpha Bot 加「对比」页：期权结构跨日对比，接替停摆的 Options compare daily 任务（数据改读每日扫描结果，不再依赖深度报告）
<!-- 认领：claude/alphabot-options-compare 2026-11-11T01:30:52-07:00 a49dcb59 -->

背景：Cowork 定时任务「Options compare daily」跑 `~/Desktop/深度分析报告/规则/compare_engine_v2.py`，用正则从深度报告 HTML 里抠期权读数，
所以要先手动跑完 NVDA 深度报告才有输入；最后一份产物是 2026-05-20，深度报告生成器 v0.45.724 退役后永久断供。同一批数的源头是每日扫描落盘的
`.swarm_results_<日期>.json`（OracleBee details），本版让 Alpha Bot 直接读它。

### Added
- `alphabot/options_compare.py`（新）：纯函数。`day_view` 从一只票某天的扫描结果抽期权读数（综合分 / 方向 / 现价 / 全链与近端窗口的 P/C、OI / IV Rank 及其来源 / IV Skew /
  Max Pain / OI 集中位 / 异动流汇总），取不到一律 None；`compare` 与这只票上一次有记录的扫描相减（任一边缺 ⇒ None，IV Rank 两天来源不同不比）；
  `alerts` 按 `RULES` 挂提示（方向翻转、综合分 / 全链 P/C / IV Rank / Skew / 全链 OI 的单日变化、Call 成交重心迁移——旧引擎写死 $5，改成现价的百分比），
  文字只陈述变化；`build_overview` / `build_ticker` 排成总览行与单票详情（含最近 30 个扫描日的趋势）；`views_of` 把一天的结果转成读数给服务端缓存（原始文件近 2 MB，144 天的读数合计约 4 MB）。
- `alphabot/service.py`：`compare()` / `compare_ticker()` + `_compare_day`（按 mtime + 大小缓存；坏文件报 `file_unreadable`、不当成空的一天，
  对比时越过并在返回里写明）；构造参数 `compare_root`（测试用）；`/api/method` 纯新增 `compare`（阈值给帮助页）。演示模式不读盘。
- `alphabot/server.py`：`GET /api/compare`、`GET /api/compare/{ticker}`（可带 `?date=`）。
- `alphabot/static/pages/compare.js`（新）+ `app.js` 路由 `#/compare`、`#/compare/<标的>` + `index.html` 顶栏「对比」+ `help.js` 章节 `compare` + `ALPHA_BOT_GUIDE.md` 页面表一行。
- `tests/test_alphabot_options_compare.py`（新，45 条，离线）：读数 / 变化 / 阈值边界 / 「上一次」的选取 / 读盘失败三种情形各不相同 / 夹具确实接上了 /
  前端读的字段都在服务端输出里 / 阈值不抄进前端 / 模块纯度。
- `alphabot/CLAUDE.md`：新增一条子条说明本页的数据来源与不变式。

### 口径：变化与提示只用全链 P/C、全链 OI（同日二次检查时改定）
- 扫描记的 `total_oi` / `put_call_ratio` 只数主链选中的 4 个到期日（`cboe_options._select_expiries`：8 个日历日之后最近的 4 个）。
  月度到期日（第三个周五）进出这个窗口时窗口 OI 跳 3～5 倍——只读核对 NVDA 2026-09-28～11-10 共 31 个扫描日：按全链逐到期日 OI
  重算「前 4 个到期日合计」，24 天与记录值相差 ≤ 13%，窗口含月度到期的日子在 149～194 万、不含的在 26～61 万；同期全链 OI 一直在
  1026～1194 万。其余 7 天（09-29、10-13、10-19、10-20、10-26、10-27、11-03，五个周二两个周一）记录值比重算值低 16%～83%，原因**待验证**
  （那几天主链实际选中的第 4 个到期日没有落盘，只记了前 3 个）。
- 第一版给窗口 OI 挂 ±15% 提示：10 / 11 月全部标的 836 个相邻扫描日里会响 184 次，全链口径 34 次。改为总览列、变化、提示、趋势主线都用全链；
  窗口两项只在详情页并排摆出，不算变化、不挂提示（守卫 `TestCompare::test_window_jumps_raise_no_alert`）。
- 144 个扫描日里有 53 个（最晚到 2026-09-25）整天没有全链记录：那些日子这两列显示「—」。
