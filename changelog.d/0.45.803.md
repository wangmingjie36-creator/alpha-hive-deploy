## [0.45.803] — 2026-11-23 — Fixed：对冲账本到期日收盘后，当天到期的跨式腿 Greeks 记 0（已按收盘内在价值锁定、现金结算）——不再因 CBOE 清零 IV 判「缺报价」整轮不对冲，也不再对冲已锁定的实值腿
<!-- 认领：claude/hedge-expiry-intrinsic 2026-11-23T08:18:10-07:00 2ea62f13 -->

### 起因

对冲页 11-20 显示「数据不全，对冲决定做不出来：partial data — no hedge on partial data (1 quote missing)」。缺的那张是 NVDA 财报空跨式的看涨腿 `NVDA261120C00222500`（行权价 222.5、11-20 当天到期），当晚 NVDA 收 125.53、深度虚值。前一天它是 bid=0 腿、按 v0.45.609 放行；到期当晚 CBOE 把要到期合约的 iv 记成 0（同一晚看跌腿 iv=0.0），这条腿过不了 `bid_zero_greeks_usable`（要 iv > 0）⇒ 判缺报价 ⇒ 整组 β·$Delta unknown。（看涨腿当晚的 bid / ask / iv 没落盘，「iv 被清零」是从看跌腿推断的，**待验证**。）

二次检查发现更根本的一层（用户 11-23 定改）：跨式账本到期按**到期那一场收盘的内在价值现金结算**（`options_paper_leg` 模块头「出场价」），收盘那一刻盈亏就锁定了，实值腿对标的也已没有后续敞口；而 CBOE 给实值看跌腿 delta −1.0，SPY 覆盖会继续对冲这笔已锁定的仓位，直到下一个扫描日跨式结算掉才撤（11-20 是周五 ⇒ 空挂一个周末）。

### Fixed

- `portfolio_greeks.option_exposures`：as_of == 到期日、S 是**这一场的官方收盘**（mark 的 `at_close`）⇒ 当天到期的腿**不论 CBOE 报价能不能用**，按新纯函数 `_expiry_intrinsic` 计：delta / gamma / vega / theta 全 0、mid = 锁定的内在价值（实值虚值、恰在行权价都一样），行上标 `expiry_intrinsic=True`。S 是盘中价 / 没有价 / 不是到期日 ⇒ 行为不变。
- 看得见：`aggregate().coverage.n_expiry_intrinsic`、`price_check.n_expiry_intrinsic / expiry_intrinsic`（不进 `gaps`、不告警，同 bid=0 腿）、日报覆盖行、对冲页黄条（`alphabot/hedge.py::audit_brief` 透传，`hedge.js` 提示）；压力表剔这一行并写明 `option:expiry-day intrinsic`（已到期、不重定价，同 dte ≤ 0 的处理）。
- 跨式页账本视图（`alphabot/straddle.py::position_view`）读同一份审计行：`_greek_legs` 带上 `expiry_intrinsic`、`greeks.intrinsic_legs` 点名（规则同 `degraded_legs`：合计真用上了才说），`straddle.js` 显示一行说明——否则会把记 0 的腿当成 CBOE 报价默默进合计。
- `.claude/rules/portfolio-hedging.md` bid=0 子条加指针。
- `tests/test_portfolio_greeks_expiry_intrinsic.py`（21 条）：11-20 形状（虚值 ⇒ 0、不再 partial / unknown）、实值腿报价可用也记 0 且 mid = 内在价值、恰在行权价、非到期日 / 盘中价 / 没有价行为不变、price_check / 对冲页 / 日报 / 压力表 / 跨式页的可见性、辅助函数边界。
