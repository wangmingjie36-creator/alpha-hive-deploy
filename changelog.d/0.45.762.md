### Added
- `alphabot/static/charts.js::candles`：日 K 线 + 成交量副图 + 最新收盘色块 + 滚轮缩放；水平线与 ±1σ 带包进纵轴范围。
  **逐根判**：这根有 `open` / `high` / `low` ⇒ 真 K 线（实体 = 开 → 收，影线 = 低 ~ 高，颜色按收对开）；没有 ⇒ 退回
  「前收 → 收盘」的无影线柱。悬停提示里的涨跌幅一律对前收。
- `alphabot/price_ohlc.py`（新）：开 / 高 / 低从 yfinance 取（经 `yf_daily`、`yf_gate`，`auto_adjust=False`、9 个月），按日期拼到
  Twelve Data 日线上。主干（收盘、成交量、有哪几天）不变；某天两个源的收盘相差超过 `CLOSE_TOL`（0.5%）⇒ 那根不拼、计
  `close_mismatch`；影线两端把主干收盘包进去；取不到 / 限流带原因返回、永不抛。指数票（`_SPX` / `_XSP`）不取。
  **为什么不从共享入口拿**：Twelve Data 接口本身返回开高低，是 `twelve_data._fetch_rows` 解析时只留了收盘与成交量；
  但该文件在输入层代码指纹守卫范围内、有十来个生产读者，又在评分冻结期，不为一张展示图去动它。
- `alphabot/service.py`：`AlphaBotService(ohlc_fn=…)` + `_with_ohlc`——`/api/bars/{T}` 的每根纯新增 `open` / `high` / `low`（对得上才有）
  与说明块 `ohlc`（`available` / `source` / `matched` / `missing` / `close_mismatch` / `reason`）；成功按（标的, 美东日）缓存，失败不入缓存、
  计 `stats.ohlc_failures`；注入了 `bars_fn` 而没给 `ohlc_fn`（现有测试）⇒ `not_wired`，不出网。
  `_default_bars`、`synthetic.demo_bars` 每根纯新增 `volume`（演示数据另带合成的开高低）。
- `tests/test_alphabot_price_ohlc.py`（新，16 条，全离线）：拼接对账、坏行、未复权请求、来源登记、失败可见、失败不入缓存、不出网。
