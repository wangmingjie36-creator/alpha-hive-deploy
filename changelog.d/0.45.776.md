## [0.45.776] — 2026-11-16 — Added：Alpha Bot 标的页新增「成交」子页（成交榜）：单票整条链的合约按当日累计成交量排名（只展示、不进评分）

### 起因

用户 2026-11-16 问「Alpha Bot 里有没有合约成交榜」——没有：最接近的是「对比」页的「异动流」（只收扫描判成异动的合约、按权利金排、一天一次）和盘中热力图的成交活跃度（按行权价、看增量）。用户定「加一个」。

### Added

- `alphabot/volume_board.py`（纯函数，只 import `math` / `typing`）：`build(raw)` 把原始链逐合约变成行（方向、到期、行权价、虚值 %、成交量、OI、成交 ÷ OI、bid / ask / 中间价、约成交额 = 成交量 × 现在的中间价 × 100、IV、Δ）；`select(full, params)` 筛（方向 / 到期日）→ 只留有成交的 → 排（成交量 / 约成交额 / 成交 ÷ OI）→ 截断（25 / 50 / 100 / 200），汇总（Call / Put 成交量与约成交额、Put ÷ Call、列出的占比）按筛完的整个范围算、不受截断影响。
  - **不当 0**：链里没有成交量、认不出行权价 / 方向 / 到期日的合约单独计数（页面写出来），OI 为 0 时比值为空、没有有效买卖价时约成交额为空；整条链还没有成交 ⇒ 原因码 `no_volume_today`（不是空的成功）。
  - 按「成交 ÷ OI」排时成交量不足 `RULES["vol_oi_min_volume"]`（100）的排在最后；阈值只经 `/api/method` 与接口里的 `rules` 给页面。
  - 原因码唯一表 `REASONS`；页面免责语 `DISCLAIMER`：每行是一个合约当天的成交合计、不是一笔订单，分不出买卖方向与开平仓，Call 多 ≠ 看涨，约成交额是估算。
- `alphabot/service.py`：`volume_board(ticker, params)` + `GET /api/volume-board/{T}`（`server.py`）。**不另取链**：`live()` 现算时把实际用到的原始链留在内存 `_raw_last`（最多 `RAW_KEEP` = 4 只票，约 1–2 MB / 只；轮询线程与页面同时写，加锁）；成交榜先走 `live()`（缓存内直接命中），链被挤掉时再强制现算一次。这次现算没取到链 ⇒ 先清掉旧链，不拿上一次的冒充。参数先验，错参数 ⇒ 400 + 参数名、不白拉链。`/api/method` 加 `volume_board`。
- `alphabot/static/pages/volume.js` + `ticker.js` 子页「成交」（`#/t/{T}/volume`）：成交概况五个 KPI + 成交榜表 + 导出 CSV；方向 / 排序 / 行数记在本机（被服务端拒就回缺省并写明），到期日不记。
- `alphabot/static/pages/help.js`：帮助章节「标的 · 成交榜」（`#/help/volume`），讲清各列口径、和「异动流」的区别、只展示未经检验。
- `tests/test_alphabot_volume_board.py`（31 条，全离线）：排序与只收有成交、汇总不受截断影响、方向 / 到期日筛选、成交 ÷ OI 排序把小成交量和 OI 为 0 的放最后、约成交额与虚值符号、不当 0 的计数、标的页算过后不再取链 / `force` 重取 / 链被挤掉只重算一次 / 重取失败不复用旧链、错参数在取数前被拒、HTTP 路由、纯度（含有牙测试）、子页与帮助接线、阈值只经 rules。

### 二次检查修掉的（同日，未合入前）
