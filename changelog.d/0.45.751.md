## [0.45.751] — 2026-11-09 — Changed：sentiment.pct 刻意池化复检——用户定直接切、不看 IC（改挂 `buzz.comp.*` self 边，起点 10-09）；Buzz 价格三通道（波动率 / 动量 / 量比）的探索性 IC 只用真实观测（新增真实观测闸）

**起因**：v0.45.565 把 `sentiment.pct` 跨 v0.45.445（10-09 新闻主源 AV → Massive）登为刻意池化，复检日 11-03。到期时条件已满足（10-09 起已结算 t7 交易日 14 ≥ 10，只数日期）。
登记的做法是算 10-09 起新世代 IC 与池化结果比；但 pct 是 Buzz 合成值，H1（buzz_v1_np）的三个情绪通道就在里面、窗口与 H1 同期 ⇒ 照做等于部分揭盲 H1。
用户 2026-11-09 定：**直接切，不看 IC**（漏切不可逆，多切只损失探索性样本）。

**代价**（生产库只读计数，未读收益；`load_panel` 口径 = 已回填 t7 的行）：探索性 IC 报告里 pct 的 t7 样本从池化的 2080 行剩 10-09 起的 381 行（13 天；10-28 按日历已过 T+7、库里还没回填，回填后 +30）；t30 清零，等 10-09 那批 t30 结算后重新攒。
H1、生产评分、维度 IC 协议都不读它的世代，不受影响；`generation_boundaries` 全部入档信号逐个比对，**只有 sentiment.pct 一个起点移动**（全史 → 2026-10-09）。

  - `SIGNAL_LEAVES` 移出 `sentiment.pct`；v0.45.445 条目的注释改为「经 self 边由 news_signal 带出」。
  - `DELIBERATELY_POOLED` 清空，留一段注释记结论；机制保留（以后再有「已知换了、先不切」照此登记）。

  - **新增 `REAL_OBSERVATION_GATES`**（用户 2026-11-09 定「让这个通道的 IC 只用真实观测」，随后「一并处理」扩到动量 / 量比）：闸 = `input`（同一 (日期, 标的) 上必须入档、且不在 `QUARANTINE` 里的输入）+ `sentinel` / `sentinel_before`（输入等于该值即旧缺失哨兵）+ `fallback_value`（通道恰为回落值即排除，只用在真实输入几乎落不到该值的通道上）。
    - 波动率 `buzz.comp.volatility_signal`：输入 `price.volatility_20d` 入档，08-26 前的 0.0（v0.45.3 之前的缺失哨兵）排除。
    - 起因：取不到波动率时生产照写回落值——08-26 前缺失记成 0.0 落进最低档 = **假 75**（「低波动、平稳」），之后是中性 **50**。生产库：前者 283 行 / 24 天，后者 170 行 / 8 天（最近 11-02）。缺失值不入档，所以「没有输入这一行」= 取不到。
    - 为什么不切 08-26 世代：切世代会把 08-26 前的真实观测一起扔掉；闸只扔非观测的行。生产库 t7（只读计数）：本该进面板 2080 行 → 保留 **1815**、排除缺失 96、旧哨兵 169（改切 08-26 世代只剩 1189，且其中仍含回落 50）；t30 保留 1198 / 缺失 62 / 哨兵 169。
    - 为什么不在入库口拦（与 `QUARANTINE` 不同）：冻结版 buzz_v1 的桥接与描述项要逐位复现生产写下的全部 7 个通道（含回落值）。闸只作用于探索性 IC 的唯一取数口 `load_panel`；维度 IC 不走它。
    - 排除不静默：`load_panel(gate_stats=)` 按信号计数，`analyze()` 报告带 `real_obs_gates`，世代小节打一行「真实观测闸：… 保留 / 排除」。
    - 动量 `buzz.comp.momentum_signal`：输入 `price.momentum_5d` 入档 + **通道恰为 50.0 排除**。有值时映射 (clamp±10+10)/20×100，只有动量恰好 0 才落到 50.0；按通道值判是因为入档的动量是 Scout 那份、与 Buzz 当时读到的不逐位相同（都在的 2524 行里 1483 行按映射对得上），08-26 NVDA、09-11 WMT 就是 Scout 有值、Buzz 回落 50。08-15 前的 0.0 哨兵（197 行）通道也全是 50.0，一并被这条接住。代价：真实动量恰为 0 的行也排除（没见过）。t7：保留 **1931**、输入被隔离 1（10-14 BILI，见下）、输入缺失 44（09-15 / 09-24 / 09-25 被隔离的动量——09-25 通道与 09-24 逐位相同，是同一个陈旧值算的；03-23/25、09-17 输入没入档而通道非 50，当时读到什么核对不了，待验证）、回落值 104；t30 1281 / 44 / 104。
